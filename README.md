#  PahanaEdu Bookshop Billing System – Backend

This is the **backend** of the PahanaEdu Bookshop Billing System, developed using **Java 21**, **Spring Boot**, and **MySQL**. It handles user authentication, customer management, item inventory, and bill generation.

---

##  Technologies Used

- Java 21
- Spring Boot
- Spring Security (JWT)
- Spring Data JPA
- MySQL
- Lombok
- IntelliJ IDEA
- Maven
